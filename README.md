# godot-android-slim

Godot 4.7.2 Android export template (template_release, arm32 + arm64) built without the engine features a 2D game
does not use (3D, 3D physics, navigation, XR, video, WebRTC/WebSocket, and similar). Base flags match the official
templates. The build recipe is in `.github/workflows/build.yml`; the result is attached to the Releases.
